## 结果与限制

- 50×50：19 项中 16 项正确命中；非等比拉伸、切掉线索、较强模糊未命中，回退 OCR 也不正确。命中耗时约 0.18～0.56 秒。
- 30×25：19 项中 11 项正确命中，加白边另外能正确回退识别；缩到 50%、非等比拉伸、缺失线索、旋转、透视等仍不稳定。
- 全部缓存命中样本的线索与当前棋盘均逐项一致。4 个真实异题负样本无错误复用；另有同尺寸换题的自动回归测试。这是有限样本证据，不能据此宣称零误判。
- 首轮暴露轻微旋转、加边的特征不足问题。增加 2500→5000→8000 特征点的渐进重试后，50×50 的相关问题修复，保持 99.5% 阈值不变。
- 裁掉线索属于信息缺失，理应不命中；回退不能凭空恢复已缺失的数字。
- 弱点是低分辨率与模糊、非等比变形，以及较小棋盘的旋转/透视。当前回退 OCR 不等于识别正确；暂不能承诺所有变换都支持。

## 复现

```bash
python -B tests/robustness_benchmark.py /tmp/nonogram-robustness
```

生成图片和原始结果保存在给定目录，未写入仓库；本次结果摘要保存在 [robustness-results.json](robustness-results.json)。此脚本独立于常规单元测试，单样本 OCR 在支持 SIGALRM 的系统设置 10 秒上限。

本报告对应题目级整体复用与渐进特征点重试方案。
